# חברותא — מציאת חברותא ללימוד

אפליקציית Web בעברית למציאת חברותא, פרסום בקשות לימוד וניהול התאמות. הממשק מותאם למובייל ולכתיבה מימין לשמאל (RTL).

## מצב הפרויקט

**אב־טיפוס עובד בדפדפן — עדיין לא מערכת ייצור מאובטחת.**

הקוד הופרד לקובץ כניסה נקי, קובץ JavaScript וקובץ CSS. נשמרה גרסת האפליקציה הקיימת; השינוי הוא בעיקר בארגון הקבצים ובהוספת בדיקות smoke בסיסיות.

## הפעלה

### הרצה מקומית
אפשר לפתוח את `index.html` בדפדפן. מומלץ להפעיל שרת סטטי מקומי, למשל באמצעות Live Server ב-VS Code.

### בדיקות
נדרשת Node.js בגרסה 18 ומעלה. בתיקיית הפרויקט הריצו:

```bash
npm test
```

הבדיקות בודקות את מבנה דף הכניסה, קיום קובצי הנכסים ומספר סימנים בסיסיים לכך שקוד האפליקציה נטען. הן **אינן** בדיקות end-to-end, אבטחה או אימות מלא של כל התכונות.

### פרסום ב-GitHub Pages
1. היכנסו ל-**Settings → Pages** במאגר.
2. תחת **Build and deployment**, בחרו **Deploy from a branch**.
3. בחרו את הענף `main` ואת התיקייה `/(root)`, ושמרו.
4. לאחר שהפרסום יסתיים, GitHub יציג את כתובת האתר באזור Pages.

## מבנה המאגר

```text
-my-new-project/
├── index.html           # נקודת כניסה לאפליקציה
├── assets/
│   ├── app.js            # קוד JavaScript ארוז של האפליקציה
│   └── styles.css        # עיצוב האפליקציה
├── tests/
│   └── smoke.test.js     # בדיקות בסיסיות
├── package.json          # פקודת npm test
└── README.md             # תיעוד
```

## מה כולל האב־טיפוס

- ממשק בעברית ובכיווניות RTL.
- פרופיל משתמש ותחומי לימוד.
- בקשות למציאת חברותא, התאמות וחברותות פעילות.
- מסכי משתמש וניהול, כולל טיפול בדיווחים וחסימת משתמשים.
- הדגמה של מסכי התחברות וקישור Google.
- שמירת נתוני הדמו בדפדפן באמצעות `localStorage`.

## חשוב לפני פיילוט אמיתי

הגרסה הנוכחית היא אב־טיפוס מקומי. נתונים שנשמרים ב-`localStorage` נמצאים בדפדפן של המשתמש ואינם מסד נתונים משותף בין משתמשים או מכשירים. מסכי התחברות, הרשאות מנהל ו-Google שמופיעים בדמו אינם תחליף לאימות והרשאות בצד שרת.

לפני שימוש עם משתמשים אמיתיים יש להשלים ולבדוק לפחות:

- חיבור backend ומסד נתונים משותף, למשל Supabase.
- אימות משתמשים אמיתי, כולל הגדרת Google OAuth בצד ספק הזהות.
- הרשאות בצד שרת ומדיניות RLS לכל טבלה; אין להסתמך על בדיקות הרשאה בצד הדפדפן.
- הסרת פרטי התחברות לדוגמה והגנה על מידע אישי.
- בדיקות אבטחה, פרטיות, נגישות ותפקוד במכשירים שונים.
- בדיקת תהליך פריסה מלא לפני שמזמינים משתמשים.

**אין להזין כרגע מידע אישי או רגיש של משתמשים אמיתיים לגרסת הדמו.**

## מצב הקוד

קובץ JavaScript הוא עדיין bundle ארוז ולא קוד מקור מפוצל לרכיבי React. אין כרגע תהליך build או סביבת פיתוח מלאה עם תלותים מוגדרים. לכן השלב הבא לשיפור התחזוקתיות הוא לשחזר מבנה מקור מודולרי ולבדוק אותו מול הגרסה הנוכחית לפני החלפה.

## תרומה ושינויים

בצעו שינויים בעיצוב בתוך `assets/styles.css`, בקוד האפליקציה בתוך `assets/app.js`, ובמבנה המסמך בתוך `index.html`. מומלץ לשמור כל שינוי ב-commit נפרד כדי שאפשר יהיה לעקוב ולחזור לגרסה קודמת.
