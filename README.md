# חברותא

אפליקציה קהילתית למציאת שותף או שותפה ללימוד תורה. הממשק החדש תומך בעברית ובאנגלית, מותאם לנייד, ומחובר לאימות Google דרך Firebase ולמסד Postgres עם הרשאות ברמת השורה.

## מה חדש ומה מפורסם

| חלק | מצב | כתובת / מיקום |
| --- | --- | --- |
| האתר הישן | דמו מקומי, עדיין מפורסם דרך GitHub Pages | https://efi770.github.io/-my-new-project/ |
| האפליקציה החדשה | אימות Google אמיתי ומסד משותף; גישה פרטית, לא פתוחה לציבור | https://chavruta-preview.efie770.workers.dev/ |
| הקוד החדש | ענף הפיתוח המעודכן | `dev/frontend-rebuild` |
| מקור האתר הישן | נשמר ללא החלפה | `main` |

זהו מאגר אחד עם גרסאות עבודה נפרדות, לא שני מאגרי חברותא. שמירת קוד בענף פיתוח אינה מפרסמת אותו אוטומטית בכתובת GitHub Pages. האייקון הישן באייפון ממשיך לפתוח את כתובת האתר הישן עד שתבוצע התאמה מפורשת של הפרסום.

## האפליקציה החדשה

- כניסה עם Google בלבד בגרסה המתארחת; אין סיסמאות אפליקציה או כפתורי דמו.
- הצהרת גיל18+ ומגדר עצמי. ההתאמה באותו מגדר נאכפת במסד הנתונים.
- בחירת מועמדים פרטית; התאמה רק כששני הצדדים בחרו.
- בקשת חיבור, אישור, והסכמה נפרדת של שני הצדדים לפני הצגת פרטי קשר.
- ימים, עד ארבעה טווחי שעות לפי שעון ישראל ומשך לימוד מועדף. אין סינון אוטומטי חדש לפי חפיפת שעות.
- נתוני בדיקה מסומנים ומופרדים ממשתמשים אמיתיים. הם אינם מוצגים כאנשים אמיתיים.

כניסה והרשמה אמיתיות עברו בדיקת שימוש. שמירת שעות אמיתית אומתה. בדיקות האימות, הרשאות הנתונים, ההתאמות וההסכמה כוללות בדיקות חתימה ובדיקות מסד; אין בכך טענה שכל מסלול נבדק בשני חשבונות Google אמיתיים.

## מה עדיין לא פתוח לציבור

הגישה הציבורית נשארת סגורה. פרטי המפעיל וערוץ פניות ציבורי עדיין דרושים; מסמכי המדיניות הם טיוטה. מדיניות שימור מזהה לאחר מחיקה והצטרפות מחדש עדיין דורשת החלטה. מחיקה אמיתית של זהות Firebase לא נבדקה על חשבון המשתמש הקיים.

אין לפרסם לפני השלמת פרטי המפעיל, בחירת מדיניות המחיקה ובדיקת הגרסה שנבחרה לפרסום. שדרוג בתשלום, כרטיס או חשבון חיוב אינם חלק מהתצורה המאושרת.

## מבנה הקוד

| תיקייה | שימוש |
| --- | --- |
| `app/` | מקור React/Vite של הממשק החדש |
| `server/` | API, אימות והרצת בדיקות מקומיות |
| `worker/` | האירוח הנוכחי והחיבור למסד |
| `supabase/migrations/` | סכמת Postgres, הרשאות RLS ומיגרציות |
| `tests/`, `server/harness/`, `scripts/` | בדיקות וחומרי פיתוח |
| `index.html`, `assets/` | קובצי הדמו הישן, נשמרים לתאימות ולהיסטוריה |
| `docs/` | תיעוד, מפת גרסאות ומצב פרסום |

הדמו הישן הוא לא מערכת ייצור מאובטחת. אין להזין כרגע מידע אישי או רגיש בדמו הישן.

נתוני הדמו הישנים נשמרים בדפדפן ב-localStorage. אין להעתיק אותם אוטומטית לחשבונות האמיתיים. שינוי אירוח אינו מצדיק מחיקה או שינוי של נתוני דפדפן קיימים.

## עבודה ובדיקות

```sh
npm ci
npm --prefix server ci
npm --prefix app ci
npm --prefix app run build
npm test
bash scripts/test-api-firebase-local.sh
```

חלק מהבדיקות דורשות Postgres מקומי וכלי דפדפן. בדיקות Firebase המקומיות משתמשות במפתחות בדיקה מקומיים, לא בחשבונות Google אמיתיים. אסור להפעיל מעקף אימות בדיקות בגרסה המתארחת.

אין לשמור סיסמאות, טוקנים, מפתחות פרטיים או קובצי חיבור למסד ב-Git. נתוני החיבור של האירוח מנוהלים מחוץ למאגר. מזהי פרויקט ותצורת לקוח Firebase אינם תחליף להרשאות שרת.
